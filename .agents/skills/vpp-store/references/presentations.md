# Apresentacoes

- Formato 16:9, canvas marfim e margens generosas.
- Capa: titulo serifado, uma fotografia forte e pequeno bloco verde.
- Conteudo: Manrope; no maximo 60 palavras por slide.
- Usar verde para conclusoes e terracota apenas para um destaque.
- Graficos usam verde floresta, salvia, terracota e cinza quente, nessa ordem.
- Evitar molduras decorativas copiadas das referencias; usar recortes fotograficos simples.
